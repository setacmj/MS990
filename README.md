# Wellcome Collection MS.990 — Digital Diplomatic Edition & English Translation

A complete digital diplomatic transcription, English translation, TEI P5 XML edition, and interactive web explorer for **Wellcome Collection MS.990** (*Compendium of Medicine and Surgery*, Austro-Bavarian Franciscan provenance, ca. 1650–1680), compiled from the Wellcome IIIF digitisation (`b18775275`).

## Key Contents
- **Interactive Explorer (GitHub Pages):** `docs/index.html` (also `ms990_explorer.html`), featuring side-by-side IIIF facsimile viewing, line-level coordinate overlays, and multi-state anatomical flap switching (*Klappbild* on p. 48).
- **TEI P5 XML Edition:** `MS990_tei.xml` (741 pages, 55,875 aligned German/English lines, 189,488 lines of validated TEI XML).
- **Parallel & Monolingual Editions:** `MS990_parallel_edition.md`, `MS990_parallel_edition_with_facsimiles.md`, `MS990_parallel_edition_with_facsimiles.html`, `MS990_transcription.txt/.md`, and `MS990_translation.txt/.md`.
- **Methodology & Corpus Review:** [MS990_Methodology_and_Corpus_Review.md](MS990_Methodology_and_Corpus_Review.md) documents the IIIF acquisition, Gemini 4 / Gemini 4 Hydrogen transcription workflow, quantitative consistency audit, known limitations, and thematic summary.
- **Build Pipeline:** `generate_edition_outputs.py`, `build_parallel_md.py`, `build_parallel_with_facsimiles.py`, `build_explorer_html.py`, `extract_iiif_structure.py`, and batch modules `pages_batch2.py`–`pages_batch28.py`.

## Note on Facsimile Images & Large JSON
Local facsimile JPEGs (`*.jpg`, `images/`) are excluded from Git; the HTML and Markdown editions automatically resolve images via Wellcome Collection's public IIIF endpoints. `MS990_edition_data.json` (63 MB) is excluded from the Git tree to stay below GitHub's 50 MB file-size warning and can be regenerated by running `python3 generate_edition_outputs.py` or attached to a GitHub Release / Zenodo record.
